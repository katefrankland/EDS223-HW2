# EDS223-HW2
EDS223 Homework 2 Assignment, Exploring Patterns of Environmental Justice 

### Repository Purpose: 
- The purpose of this repository is so store the analysis for our homework assignment, Exploring Patterns of Environmental Justice. The data used includes HOLC red lining maps, EPA EJScreen data, and LA County crash data. The goal of this assignment is to see if historical redlining still has environmental and transportation impacts.

### Data 
**HOLC data** : The HOLC data shows redlining boundaries and defines neighborhoods using grades A-D for LA County. 

**EJScreen data** : Sourced from the EPA, this data looks at the environmental and demographic characteristics at the census tract level. 

**LA County Crash data**: This dataset contains collision records for bike and pedestrian crashes. For this assignment, we will be looking at the years 2020-2025.
